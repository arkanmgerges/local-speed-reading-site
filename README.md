# Local Speed Reading Site

This repository hosts the public website and privacy policy for the **Local Speed Reading** Android application.

## Pages

- Website: https://arkanmgerges.github.io/local-speed-reading-site/
- Privacy Policy: https://arkanmgerges.github.io/local-speed-reading-site/privacy.html

## Purpose

The repository contains only public-facing static pages used for the app's Google Play listing and compliance information.

The Android application source code is maintained separately and is not published in this repository.
